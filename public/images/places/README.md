# Outer Banks editorial photographs

These photographs are licensed individually, independently of the website source. `credits.json` identifies each photographer, original source, license URL and the local 640px/1280px derivatives. The derivatives retain the listed image license, including ShareAlike where applicable. They have been resized and converted to WebP; the website crops the display using CSS. No generative edits were made.

The images illustrate local architecture and regional settings. They do not identify insured customers, represent available listings or imply the property owner's endorsement. Captions identify the photographed location; a `Regional view` prefix identifies photographs reused on a different town's guide. Exact alt descriptions cover the visible subject rather than insurance keywords.

The homepage painting, Allen illustration and Piper brand artwork are maintained separately.
