# OBXNCInsurance.com Brand Voice

## Must-Follow Website Copy Rule
All website copy is written for homeowners, property owners, buyers, and Outer Banks community members. Internal SEO strategy language must never appear in visitor-facing content.

## Forbidden Visitor-Facing Language
Do not publish copy that says or implies:
- "This page targets..."
- "This query..."
- "Google is testing..."
- "Search Console shows..."
- "Rank for..."
- "Searches should land..."
- "Keyword intent..."
- "SEO/GEO strategy..."

These phrases are acceptable only in internal planning notes, never on the website.

## Preferred Voice
Use clear, consumer-facing language:
- "If you are comparing..."
- "Start here to understand..."
- "Use this guide to prepare..."
- "Homeowners should gather..."
- "This can help owners understand..."
- "The review should include..."

The brand voice is transparent, educated, informed, kind, local, and practical. The site should feel like a trusted Outer Banks insurance education hub, not an SEO page.
