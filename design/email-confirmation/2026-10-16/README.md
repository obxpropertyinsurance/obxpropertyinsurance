# Confirmation email design review

Open `index.html` through the existing local Vite server to compare three concepts. These are review artifacts, not active sending templates. The verified production plain-text receipt remains in place.

The user requested a team of email marketing designers and copywriters. Three specialists developed and critiqued the directions, using the approved Piper bird, coastal painting, Fraunces and cream/navy/coral palette. All sample details are fictional.

| Concept | Primary strength | Tradeoff |
| --- | --- | --- |
| 01 · A personal welcome | Personal reassurance, human portrait, natural reading flow | Less visually coastal |
| 02 · A coastal welcome | Distinctive OBX identity, painting and warm receipt | Longest visual reading path |
| 03 · Your request, clearly | Easy-to-check request recap and practical preparation | More structured and less personal |

The final art-direction recommendation is option 2 for this brand, with option 1 strongest for conversational warmth and option 3 strongest for scanning. These are design judgments, not measured conversion results. Each specialist's Markdown file contains copy rationale, subject alternatives and implementation notes.

All three confirm receipt before asking for anything else, preserve the email-first preference, distinguish Piper from human review and provide one optional reply action. No named agent, response deadline, completed-review state or coverage guarantee is invented. No external fonts, pixels, redirects or real customer data are included.

The gallery includes desktop/mobile width controls and a Georgia fallback preview. Email-preview links are intercepted so the review page does not send mail. Standalone HTML files contain the proposed mailto links. Relative imagery and font paths are for local review; final delivery requires approved absolute asset URLs, escaped conditional personalization, a matching text alternative and inbox testing.

Browser QA covered the three 390px layouts, gallery phone width, loaded imagery, fallback-font toggle and modal controls. A small narrow-screen masthead overflow in option 3 was corrected. Browser previews are not Gmail/Outlook certification; images-off, dark mode and actual inbox checks remain part of implementation after selection.

`comparison.png` is the full comparison board. Existing production artwork is referenced, not duplicated. No website SEO, forms, sitemap, analytics or live email template was changed for these concepts.
